# Tiny Model Comparison

This experiment is a deliberately small probe, not a full language model. It
tests whether a positional/compositional mechanism exposes ordered information
to a trainable readout.

## Synthetic Task

Each example is a sequence containing exactly:

```text
3 nouns, 3 verbs, 3 modifiers
```

Every example has the same length and the same bag of roles. Only order changes.

The label is generated by applying the non-abelian path transform for the full
sequence to a fixed probe vector and asking whether the resulting direction has
positive upward component. This makes the task explicitly about ordered
composition:

```text
P = S_8 ... S_1 S_0
label = 1 if (P probe)_z is above the median
```

## Compared Probes

- `standard_rope`: standard relative-position features. Since all examples have
  the same length, this feature is constant.
- `standard_rope_plus_bag`: standard RoPE plus role counts. Since all examples
  have the same counts, this is also constant.
- `nonabelian_path_rope`: flattened ordered path transform.

Each probe trains the same logistic readout.

## Expected Behavior

The standard RoPE probes should stay near chance because scalar relative
distance cannot see the order of identical-length, identical-bag sequences. The
non-abelian path probe should do much better because order is present in the
matrix product.

This is not evidence that the method improves real language modeling yet. It is
evidence that the mechanism carries a kind of ordered compositional signal that
standard RoPE does not carry by itself.

## First Result

Using the bundled NumPy runtime:

```text
model                       train      val     test  test_loss
standard_rope               0.510    0.496    0.456      0.695
standard_rope_plus_bag      0.510    0.496    0.456      0.695
nonabelian_path_rope        0.974    0.968    0.996      0.067
```

This is the expected behavior for this controlled task. RoPE and RoPE plus bag
counts cannot distinguish examples because all examples share the same length
and role counts. The path feature succeeds because non-commuting products expose
the order of local role transitions.
